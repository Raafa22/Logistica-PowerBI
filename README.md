# Logistica-PowerBI
Projeto Logístico: Dashboard de Entregas e Prazos (Power BI)

Projeto em Microsoft Power BI focado no monitoramento de pontualidade, atrasos e volume de entregas. Transforma dados operacionais em painéis interativos para mapear a eficiência da distribuição por região.

Objetivo
Analisar a performance das entregas para identificar gargalos operacionais e otimizar o cumprimento dos prazos.

Indicadores e Visões da Análise

Total de Entregas e Prazos: Volume geral de pedidos, percentual de pontualidade e taxa de atrasos.

Desempenho por Região e Cidade: Mapeamento geográfico destacando as cidades mais pontuais e as localidades com maior índice de atrasos.

Influenciadores de Atraso: Identificação dos principais fatores e rotas que impactam no não cumprimento dos prazos.

Narrativa Inteligente: Resumo automático dos principais destaques e variações da operação.

Tecnologias: Power BI, Power Query, DAX, CSV, GitHub.

Nota: Dados fictícios desenvolvidos para fins acadêmicos e de demonstração.
